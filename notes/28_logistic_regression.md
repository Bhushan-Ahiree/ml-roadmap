# Logistic Regression

## What is Logistic Regression?

Logistic Regression is a supervised Machine Learning algorithm used for classification problems.

Despite its name, it is used to predict categories rather than numerical values.

It is most commonly used for binary classification.

---

# Why is it Called Regression?

The algorithm estimates probabilities using a mathematical function.

Those probabilities are then converted into class labels.

Although the name contains "Regression," its purpose is classification.

---

# Output

Logistic Regression predicts the probability that an observation belongs to a class.

Example:

Probability = 0.92

Prediction = Spam

Probability = 0.18

Prediction = Not Spam

---

# Common Applications

- Spam Detection
- Fraud Detection
- Disease Diagnosis
- Customer Churn Prediction
- Credit Approval

---

# Advantages

- Simple
- Fast
- Easy to interpret
- Works well for many binary classification problems

---

# Limitations

- Assumes a relatively simple relationship between features and the target.
- May struggle with highly complex patterns.
- Sensitive to extreme outliers.

---
