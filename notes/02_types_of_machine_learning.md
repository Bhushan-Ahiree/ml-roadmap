# Types of Machine Learning

---

# Interview Questions

### What is Supervised Learning?

In Supervised Learning, the training data contains input features and the correct
output (labels). The model learns the relationship between them and predicts the
output for new, unseen data.

---

### What is Unsupervised Learning?

In Unsupervised Learning, the training data has no labels. The algorithm discovers
hidden patterns, relationships, or groups within the data.

---

### What is Reinforcement Learning?


In Reinforcement Learning, an agent learns by interacting with an environment.
It performs actions and receives rewards or penalties, gradually learning the
best strategy to maximize long-term reward.

---

### One real-world example of each.

Supervised Learning
- Predict house prices.

Unsupervised Learning
- Group customers based on buying behavior.

Reinforcement Learning
- Self-driving car learning to navigate safely.

---

### A comparison table.

| Type          | Has Correct Answers? | Goal              |
| ------------- | -------------------- | ----------------- |
| Supervised    | ✅ Yes               | Predict           |
| Unsupervised  | ❌ No                | Discover patterns |
| Reinforcement | ❌ No labels         | Learn by rewards  |


---

## Key Takeaways

- Supervised Learning uses labelled data to make predictions.
- Unsupervised Learning finds hidden patterns without labels.
- Reinforcement Learning learns by receiving rewards and penalties.
