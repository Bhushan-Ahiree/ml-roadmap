# Classification

## What is Classification?

Classification is a supervised Machine Learning technique used to predict categories or labels.

Instead of predicting a numerical value, a classification model predicts which class an observation belongs to.

Examples:

- Spam or Not Spam
- Fraud or Not Fraud
- Disease or No Disease

---

# Classification vs Regression

Regression predicts continuous numerical values.

Classification predicts discrete categories.

Examples

Regression

- House Price Prediction
- Salary Prediction
- Temperature Prediction

Classification

- Spam Detection
- Email Classification
- Customer Churn Prediction

---

# Types of Classification

## Binary Classification

The model predicts one of two possible classes.

Examples

- Yes / No
- True / False
- Fraud / Not Fraud

---

## Multi-class Classification

The model predicts one class from more than two possible classes.

Examples

- Cat
- Dog
- Bird

or

- A
- B
- C
- D

---

# Common Classification Algorithms

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

---

# Applications

Classification is widely used in:
